Rally Xtreme - موقع اللعبة

الملفات:
- index.html : اللعبة
- manifest.webmanifest : إعدادات التطبيق (الاسم، الأيقونة، الوضع الأفقي)
- sw.js : تشغيل بدون إنترنت بعد أول زيارة
- icon-192.png / icon-512.png / icon-maskable-512.png : الأيقونات
- privacy.html : سياسة الخصوصية

الرفع:
1) ارفع كل الملفات (ما في مجلد داخلي، الملفات بالجذر) على استضافة https مثل Netlify Drop أو GitHub Pages أو Cloudflare Pages.
2) افتح الرابط من Chrome على الجوال.
3) ⋮ ثم "تثبيت التطبيق".

تحديث اللعبة: بعد أي تعديل على index.html غيّر اسم الكاش في sw.js (من rx-v3 إلى rx-v4) عشان المستخدمين يحصلون على النسخة الجديدة.
